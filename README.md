- RE:Judgement Skins for all. (Custom redone Judgement Skins.)
- Anointed Skins for all. (Based on Starstorm!)
- Sepiatone Skins for all. (Based on the overshadowed CSS, as per request from Officialcord. Hi guys!)
- Nemesis Skins for the Original Cast. (Starstorm Staple.)
- Mastery Skins for all except Enforcer, Pilot, Drifter, & Mercenary. (Oni is covered by the P2 skin)
- Starstorm Variant Skins for all except Enforcer, Pilot, Artificer, &  Drifter. (Heavy is covered by the P4 skin)
- And several more that are scattered about.

## !!MANUAL INSTALL ONLY!!
To install this skin pack, place the contents of the 'skins' folder within Drip or Drown into the 'skins' folder of Under Your Skin.
If you're using R2ModManager, these folders can be accessed via R2's Settings by clicking "Browse Profile Folder" and following ReturnOfModding -> Plugins, where you will find all mods' folders.

Works online if everyone has the pack installed exactly the same.
If you can't see all of the skins at once, use your movement keys to select them from off screen.
